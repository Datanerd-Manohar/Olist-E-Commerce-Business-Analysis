# Olist-E-Commerce-Business-Analysis
Understanding sales performance, customer behavior, product performance, payment analysis and delivery option using SQL

# Project Overview

This project analyzes the Olist Brazilian E-Commerce dataset to understand sales performance, customer behavior, product performance,delivery operations, and payment behavior.
Rather than treating this as only a SQL exercise, the analysis was structured around 10 business investigations. Each investigation starts with a business question, 
uses SQL to analyze the data, and ends with findings and recommendations. The project concludes with an interactive Power BI dashboard for management reporting.

# Business Objective

The analysis investigates:

- Customer retention and repeat purchasing
- Monthly sales and revenue trends
- High-value customers
- Product category performance
- Product growth and decline
- Delivery performance by state
- Logistics and delivery delays
- Payment behavior and revenue contribution

# Dataset

Dataset: Olist Brazilian E-Commerce Public Dataset 
Time period: 2016--2018

Main tables:

- olist_orders_dataset
- olist_customers_dataset
- olist_order_items_dataset
- olist_products_dataset
- olist_order_payments_dataset

The analysis primarily uses delivered orders when calculating sales,revenue, customer value, and delivery metrics.

# Tools & Technologies

- MySQL / SQL --- business analysis
- Power BI --- dashboard and visualization
- GitHub --- documentation and version control
- CSV --- analysis outputs

# SQL Concepts Used

JOINs, CTEs, CASE statements, aggregate functions, COUNT(DISTINCT), date/time functions, GROUP BY, HAVING, subqueries, window functions,
RANK(), DENSE_RANK(), ROW_NUMBER(), LAG(), LEAD(), and window frames.
